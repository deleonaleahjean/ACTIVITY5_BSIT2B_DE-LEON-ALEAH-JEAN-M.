# Module 5 Activity — Stacks & Queues

This project shows how stacks and queues work using both arrays and linked lists.

## What each file does
- `stack_implementations.py` — Stack made with an array and a linked list
- `queue_implementations.py` — Circular queue using an array and a linked list queue
- `applications_exercise.py` — Checks if brackets are balanced and simulates a print queue
- `interactive_driver.py` — Menu to try everything out
- `analysis.md` — Explanation of how and why things work

## How to run it
Open your terminal in the folder and type:
```bash
python interactive_driver.py
